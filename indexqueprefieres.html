🧠 Consejos para subir imágenes

  • Puedes pegar un enlace directo de imagen (ej: https://i.pinimg.com/....jpg).
  • Las imágenes se pueden enlazar mediante URL HTTPS. La subida directa de archivos se habilitará al configurar Storage.
  • La URL es la imagen que se comparte con todos los jugadores; el archivo local solo sirve como vista previa.
  • Usá imágenes horizontales (16:9) para que se vean bien en la vista de juego.
  • Los formatos recomendados son JPG o PNG, tamaño menor a 1 MB.

Separa las etiquetas con comas (,). Ejemplo: anime, snk, acción

El texto queda centrado; podés añadir imágenes públicas mediante URL.
